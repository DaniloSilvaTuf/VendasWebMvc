# Sistema de Gestão de Vendas

Aplicação web desenvolvida com C# e ASP.NET Core MVC para gerenciamento de vendedores, departamentos e registros de vendas.

## Sobre o Projeto

Este projeto foi desenvolvido durante meus estudos em ASP.NET Core MVC, com foco na construção de aplicações web utilizando boas práticas de desenvolvimento, arquitetura MVC, Entity Framework Core e banco de dados relacional.

A aplicação permite o gerenciamento de vendedores e departamentos, realizando operações completas de cadastro, edição, consulta e exclusão de registros, além de funcionalidades de pesquisa e agrupamento de vendas.

## Tecnologias Utilizadas

* ASP.NET Core MVC
* Entity Framework Core
* MySQL
* Razor Views
* Bootstrap
* Git
* GitHub

## Funcionalidades

### Gestão de Departamentos

* Cadastro de departamentos
* Edição de departamentos
* Exclusão de departamentos
* Listagem de departamentos

### Gestão de Vendedores

* Cadastro de vendedores
* Edição de vendedores
* Exclusão de vendedores
* Visualização de detalhes
* Associação de vendedores a departamentos

### Gestão de Vendas

* Consulta de vendas por período
* Pesquisa simples de registros
* Pesquisa agrupada por departamento
* Exibição de resultados formatados
